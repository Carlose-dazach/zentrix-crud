# Zentrix – Laboratorio IV

Plataforma web para clínicas y consultorios médicos.  
Laboratorio IV de Programación Web VI – Universidad Libre, 2026-II.

## ¿Qué hace este proyecto?

Zentrix implementa un CRUD completo (Crear, Leer, Actualizar, Eliminar) usando React con hooks, un helper de Fetch y una API ficticia con json-server. La interfaz está construida con Bootstrap 5 y gestiona cuatro módulos: Servicios médicos, Pacientes, Médicos y Citas.

## Tecnologías

- React 18 + Vite
- Hooks: `useState` y `useEffect`
- Helper `helpFetch` (GET, POST, PUT, DELETE)
- Bootstrap 5
- json-server (API ficticia)
